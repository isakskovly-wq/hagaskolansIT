HAGASKOLANS IT – ISAK-TEKNIK
Version 1.0 – lokal testversion

STARTA:
1. Packa upp mappen.
2. Dubbelklicka på index.html.
3. Testa menyer, sökfunktion, guider och kontaktformulär.

DETTA FINNS:
- Startsida
- Sökfunktion
- Hjälpkategorier
- 8 felsökningsguider
- Meitner
- Skolon / Licenser
- Driftinformation
- Kontaktformulär med simulerad testanmälan
- Mobilanpassning

VIKTIGT:
Kontaktformuläret skickar ännu inget till Isak. Det är medvetet i version 1
så att sidan kan testas helt lokalt utan server eller databas.

NÄSTA STEG:
1. Anpassa guiderna till Hagaskolans faktiska utrustning och rutiner.
2. Byt ut exempeltexten i driftinformationen.
3. Koppla kontaktformuläret till skolans/kommunens godkända Microsoft 365-lösning.
4. Därefter kan vi bygga version 2 med riktig ärendehantering och dashboard.

NAMN:
"Hagaskolans IT" används som rubrik, med den interna skämtsamma betydelsen
"IT = Isak-Teknik".
